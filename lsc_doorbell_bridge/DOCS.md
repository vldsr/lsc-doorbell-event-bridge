# LSC Doorbell Event Bridge 1.0.0

Open the Web UI to configure the Tuya credentials, doorbell, Home Assistant camera, snapshot triggers and photo retention.

Supported Web UI languages: English, Italian, German, French and Spanish.

The App creates only: Motion, Pressed, Snapshot, Power mode and Battery.

For the full Tuya Cloud and Home Assistant setup, see the repository `docs/INSTALLATION.md`.
